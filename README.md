# dev-back-cheminDeLaReussite
creation du serveur back pour le TestTrading Tech(Js ; ExpressJs ; mongoose)

# start commande
version de node V22.12.0
npm install  : installer les diff paquet
npm start : pour lancer le projet

# paquet installé et version
- npm install express : pour initialisé un server express ;
- npm i nodemon : pour l'ecoute automatique du server;
- npm i dotenv : pour lire les variale d'environnement '.env';
- npm i body-parser : pour filtrer les entré de la req de manier 
        simplifié, lire les ficher JSON && x-www-form-urlencoded ;
- npm i mongoose : pour connecter avec la BD mongoDB;
- npm i cookie-parser : analyse les cookies coté serveur;
- npm i @alpacahq/alpaca-trade-api : pour communication avec alpaca Maket
